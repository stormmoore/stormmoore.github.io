Game Project: Solitaire Siege



This game was created by Stormie Moore, Brandon Williams, Shawna Vang, and Stephanie.

This game project was designed and completed in Fall 2024, during my studies at Boise State University. The game is a 2D tower defense game with AR mechanics using playing cards to activate abilities and traps along the path to the home base, deterring the enemy units. We wished to create an easily playable game with recognizable elements. Playing cards were the best fit for the idea, and what we centered out entire design around. The color schemes for the assets, sprites, and UI all matched a standard Bicycle playing card deck- to be as uniform as possible. Each member of the team was responsible for different aspects of the game. My position on the team was to design the enemy sprites, the menu screens, and the opening animation. I also had the chance to help with specific coding elements, like a teleporting trap and the enemy pathing.


This is the first game project that I have ever worked on, and the first completed in Unity. It was a great learning experience, showing me the basics of creating a 2D game, and how to work with a team to create our project. This was also my first time using Adobe Animate and Photoshop. As a result, I have learned many things about these industry standard programs. One challenge I had with Animate was being able to keep the timing of the frames I originally sketched in Photoshopjust right to make the animation smooth and not choppy. I had to adjust the timing of the frames multiple times to get it just right, practicing with the onion skin feature and timelines. If there is one thing I would change about my work on this project, it would be to spend more time creating smoother transitions for the opening animation, and clean up the frames. But even so, I am proud of the game we created and the work I put into it. All of the skills I learned from this project have been valuable for my future in designing assets and animation.
